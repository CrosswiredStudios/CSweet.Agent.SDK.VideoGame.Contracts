# 1.1.0

Add optional shared GDD coordination contracts for interoperable video-game agents.

- Add request, result, feedback/finding and scoped failure records with stable protocol
  keys. Existing request/result/feedback property names, order and key values retain
  compatibility with the per-agent payloads being replaced.
- Add machine-readable generation/review failure codes. Summary remains human text;
  consumers bind scope and inspect the code rather than matching English prose.
- Add semantic coverage criterion identifiers without imposing GDD headings or layout.
- Document raw JSON exchange for third-party agents without a CLR package dependency.
- Keep this package independent from the main Agent SDK and platform. Prompts,
  semantic review, generation recovery and workflow authority stay in agent/runtime code.

Publish this package before Director 0.6.9 and Creative Director 4.1.4, whose pins
consume it through NuGet artifacts with sibling project references disabled.

Validation: all 15 compatibility tests pass and Release pack produces 1.1.0. The final nuspec version was inspected; both agent packages pin 1.1.0 and consume the exact contract DLL from this package. Their 422 Director, 49 Creative Director and 27 cross-role tests also pass. No package was published.
