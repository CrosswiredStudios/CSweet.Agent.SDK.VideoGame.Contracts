# 1.0.0

First release. Moves the shared video-game agent contracts out of the per-agent `extensions/video-game/VideoGameContracts.cs` source snapshots into one optional package.

- Namespace `CSweet.Agent.SDK.VideoGame.Contracts` (was `CrosswiredStudios.VideoGame.Contracts` in the snapshots). JSON shapes and key values are unchanged, so agents on the package and agents still on a snapshot exchange the same payloads.
- Contents match the Creative Director's snapshot, plus `VideoGameRoleKeys.GameDirector` from the Director's copy.
- Includes `GameProposedWorkItemV1.BrowserVerification` and `GameBrowserVerification` (`canvas`, `page`, `none`), added on 2026-11-11 so planning declares the browser evidence a task's candidate must carry. The field is omitted from JSON when null, so retained planning digests do not change.
- Targets net8.0. No dependencies other than the .NET runtime. The C-Sweet Agent SDK does not reference this package.

Validation: not yet run. Written without a .NET SDK available; run `dotnet test CSweet.Agent.SDK.VideoGame.Contracts.slnx` before publishing.
